# Paste Pictures

Take a screenshot (Win+Shift+S), copy a picture from a browser or app, or copy up to 5 picture files in Explorer (PNG, JPG, GIF, BMP, TIFF). Click her Type box and press **Ctrl+V**. The picture is attached; type a message and press Enter, or just press Enter to send the picture on its own. Pasting text works like it always did.

Big pictures are shrunk before sending so they stay quick. Pasted pictures are saved in the mod's folder and cleared after a while.

**Options:** longest side of a picture (2000 px) · days to keep them (30)

Works with **DM Capri!**, which shows the pictures you pasted alongside the chat.

- Kind: code mod
- Made by: Quaisar_THM
- Needs: Capri with mod API 3 (0.8.7 or newer), Windows

### Why the mod check flags it
- **Calls Windows directly**: to set the hint text in her Type box ("Picture attached…").

No network access, no keys, nothing sent anywhere.
