# DM Capri!

Every conversation you've had with her, laid out like Discord. Click the **chat button** next to her TYPE / TALK pill, or right-click her and pick **DM Capri!**:

- Each day down the side; messages with her avatar, names and times, back-to-back ones grouped under one header
- **Clickable links** (open in your browser), and `**bold**`, `*italic*` and `` `code` `` shown properly
- A **chat bar**: type and press Enter to message her, just like her Type box, with "Capri is typing…" while she answers
  - **Shift+Enter** for a new line; the bar grows up to six lines
  - **Ctrl+V a picture** (a screenshot, a copied image, or up to 5 picture files copied in Explorer) to send it with your message; click × or press Esc to take it back
  - Commands work like her Type box: **"Capri, look at my screen"**
- Updates live while you talk; search across every day; open the transcripts folder in one click

With **Paste Pictures**, the pictures you pasted show up in the chat too.

The chat button is drawn with Capri's own button style and sits left of TYPE / TALK (left of the Mute Button mod's button if you have it), or to the right near the screen's left edge. It can be turned off in Options.

**Options:** chat button on/off · picture size · text size

- Kind: code mod
- Made by: Quaisar_THM
- Needs: Capri with mod API 3 (0.8.7 or newer), Windows
- Permissions: transcripts, chat

### Why the mod check flags it
- **Calls Windows directly**: to set the hint text in its search box, and to check her TYPE / TALK pill is on screen so the chat button shows and hides with it.
- **Starts programs**: Open folder shows the transcripts folder in Explorer, clicking a pasted picture opens it in your image viewer, and clicking a link opens it in your browser (http and https links only). Nothing else.
- **Reaches outside her folder**: pictures waiting in the chat bar sit in a temp folder (`%TEMP%\capri-chat-bar`), and sent ones go in Paste Pictures' folder, where the log shows them. To hand pictures to her it uses the same part of Capri that dropping a file on her does.

No network access, no keys, nothing sent anywhere.
